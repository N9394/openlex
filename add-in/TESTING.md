# Manual test in Word (10 steps, ~15 minutes)

The pane's logic is unit-tested in node (`cd sidecar && node --test test/addin_pane.test.js`); this checks the parts only Word can show.

**Setup.** Start the engine (`cd sidecar && npm start`), run `add-in/sideload-mac.sh`, restart Word, open a contract with numbered headings (e.g. "4. Liability"), open the pane (Home → OpenLex Chat). Use the AI on this computer first.

1. **Idle pane.** You see: matter picker + ☰ in the header; `AI: this computer` under it; an empty conversation with one hint line; `Your data: ✓ Nothing has left this computer`; the question box; **Review this contract**, **Options**, ↩. Nothing else. *Pass if* no tabs or extra panels are visible.
2. **Menu.** Press ⌘K. Type `transl` → "Translate a document" is first; arrows move, Esc closes and focus returns. Add `"features": { "translate": false }` to your `openlex.json`, reopen the pane, search again → the entry is gone. "Analyse this document" and "Matter overview" are absent (until the analysis engine change is merged).
3. **Ask + activity.** Ask "Is the liability cap enforceable under Austrian law?". *Pass if* at most three plain-language steps show (current one bold, ▸), never a tool name; when done they fold to `✓ Done in … · N steps — what it did`, which expands.
4. **Based on.** Under the answer: `Based on ① ②…`. Click a law number → passage + **Read the full text** shows the section. Click a document number → **Show it in the document** selects that clause in Word.
5. **Data line.** Switch to a cloud AI service with the redaction check on (Settings: which AI / where client data may go) and ask again. *Pass if* the line reads `! Sent to Claude (Anthropic, EU) — names and numbers hidden (pseudonymised), checked by you · N times` (symbol + words). Ask something that searches RIS → `· Looked up online: RIS`. Switch back to the AI on this computer → `✓ Stayed on this computer`.
6. **Stop.** Ask a long question and press **Stop** (or Esc in the question box) while it writes. *Pass if* the partial answer stays and a line says what was kept and that nothing more is sent. Type a half question, close and reopen the pane → your draft is still there.
7. **Permission card.** Ask "save the obligations of this contract as a CSV file". *Pass if* the card asks one question ("May OpenLex save … ?"), **Allow once** has the focus ring, Enter allows once, and on a second try Esc answers "Don't allow". "Always" is never pre-selected. Tab reaches every button.
8. **Review this contract.** Press **Options**: choose *Customer / buyer*, a checklist, *Liability*; **Start the review**. *Pass if* the card shows `Clause N of M · clause … · about … left` and a progress bar; tracked changes and comments ("OpenLex: … / Legal basis: … / checked against …") appear in the document while it runs; at the end the card starts with one line (`2 high risks, 3 medium`).
9. **Findings and anchor failures.** While a review runs, delete a sentence OpenLex is about to change (or edit a clause). *Pass if* that finding is marked `! The words this is about were not found…` and **Insert as comment instead** puts a comment on the clause heading (or at the cursor). Use **Accept** / **Reject** on two findings → the card counts them; **Save the review as Word** and **Save as PDF** report a file in your files folder, and **Show the file** reveals it.
10. **Theme and accessibility.** Switch Word between light and dark (Word → Preferences → General → Appearance / File → Account → Office Theme) and reopen the pane → it follows (Settings → Colours: *Match Word*). Turn on "Reduce motion" (macOS Accessibility → Display) → the current-step shimmer stops. With VoiceOver on, ask a question: it announces the steps and "Answer ready", and reads the permission question.
11. **Settings and tables.** Open Settings → five short rows (AI, Where client data may go, Answers in, Colours, About and updates) and a closed *Advanced*. Set *Answers in* to English, untick *Add a Word comment* under Advanced, reload the pane → both are kept. Ask for a comparison "as a table" at 320 px width → a real table that scrolls sideways inside the answer, not `| … |` text. When OpenLex asks "May OpenLex …?", the question is fully in view and the hint under the question box is hidden until you answer.

Report anything that shows engine words (tool names, JSON, model ids), colour without a symbol, or a lost question.
