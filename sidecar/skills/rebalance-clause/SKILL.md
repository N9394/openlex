name: rebalance-clause
title: Rebalance a clause
description: Redraft one clause so it is fairer to (or more favourable for) the lawyer's client, keeping it complete and signable.
triggers: [rebalance, fairer, make it fairer, favorable, more balanced, more favourable, favour our client, ausgewogener, zu unseren gunsten, prerobiť v prospech]
output: suggestions
---
1. Identify the target clause from the request or the selection and the client side. If the side is unclear, ask in one line instead of guessing.
2. Read the clause and the clauses it refers to (definitions, caps, notices).
3. Check the firm's own wording first: find_clause or search_firm_library for the same clause type, and prefer the firm's language.
4. If the change touches mandatory law (consumer, employment, liability for intent or gross negligence), search_law first.
5. Redraft granularly: one suggestion per changed sentence, each anchored to the exact original text. Keep every operative element of the original.

Output: suggestion cards; one line explaining the commercial effect.
